
# Project Overview

## Project Name

Claude Code Workshop

## Organization

dev-foundry-lab

## Purpose

Learn Claude Code through practical exercises
focused on software development, UX/UI design,
AI agents and reusable automation workflows.

## Goals

- Understand Claude Code configuration and memory.
- Build web applications using AI-assisted workflows.
- Learn to design and organize reusable skills.
- Experiment with agents and automation.
- Establish repeatable development practices.

## Scope

The repository contains educational materials,
configuration examples and practical exercises.

Workshop exercises may include:

- React and Next.js applications
- TypeScript development
- UX/UI workflows
- AI agent configurations
- Reusable skills

## Development Approach

- Work incrementally.
- Complete one exercise at a time.
- Validate results before proceeding.
- Document important architectural decisions.
- Keep examples reproducible.

## Success Criteria

- Exercises can be reproduced on a new machine.
- Project instructions are documented.
- Architectural decisions are traceable.
- Example applications can be validated.
- Skills can be reused in future projects.
