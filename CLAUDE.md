
# Claude Code Workshop

## Project Overview

This repository belongs to the `dev-foundry-lab`
GitHub organization.

Its purpose is to learn and experiment with Claude Code
through practical exercises involving:

- Web application development
- Frontend architecture
- UX/UI design workflows
- AI agents and automation
- Reusable Claude Code skills

This repository is primarily educational.

## Preferred Tech Stack

- TypeScript
- React
- Next.js
- Node.js
- pnpm

Do not assume these technologies are installed.
Inspect the project before making technical decisions.

## Project-Specific Coding Rules

- Use clear and descriptive names.
- Prefer small, reusable functions and components.
- Follow the existing project architecture.
- Keep workshop examples simple and understandable.

## Workshop Workflow

- Explain the proposed approach before modifying code.
- Identify the files involved in each exercise.
- Proceed one exercise at a time.
- Wait for confirmation before moving to the next exercise.
- Explain why new dependencies are needed before installing them.

## Project-Specific Safety

- Never delete project files without explicit approval.
- Avoid destructive Git commands.

## Project Documentation

Project knowledge is maintained in the `docs/` directory.

Relevant documents:

- `docs/project-overview.md`: project purpose, goals and scope.
- `docs/architecture.md`: current architecture and technical principles.
- `docs/decisions/`: Architecture Decision Records (ADRs).

Before making architectural decisions:

1. Read the relevant project documentation.
2. Check existing ADRs for previous decisions.
3. Distinguish documented facts from assumptions.
4. Propose a new ADR when introducing a significant architectural decision.

Do not assume that planned components are already implemented.
