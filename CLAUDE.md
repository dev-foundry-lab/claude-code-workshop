
# Claude Code Workshop

## Project Overview

This repository belongs to the `dev-foundry-lab` GitHub organization.

Its purpose is to learn and experiment with Claude Code
through practical exercises involving:

- Web application development
- Frontend architecture
- UX/UI design workflows
- AI agents and automation
- Reusable Claude Code skills

The repository is primarily educational.

## Tech Stack

Preferred technologies for workshop projects:

- TypeScript
- React
- Next.js
- Node.js
- pnpm

Do not assume that all these technologies are already installed.
Inspect the project before making technical decisions.

## Coding Standards

- Prefer TypeScript with strict type checking.
- Avoid using `any` unless explicitly justified.
- Use clear and descriptive names.
- Prefer small, reusable functions and components.
- Avoid unnecessary dependencies.
- Follow existing project conventions.
- Do not introduce abstractions without a clear benefit.

## Development Workflow

Before implementing changes:

1. Inspect the relevant project files.
2. Explain the proposed approach.
3. Identify the files that need modification.
4. Implement the smallest reasonable change.
5. Run relevant validation commands when available.
6. Summarize the changes and any remaining issues.

## Safety Rules

- Never delete files without explicit approval.
- Never expose secrets, tokens or credentials.
- Never modify `.env` files without permission.
- Never install dependencies without explaining why.
- Never push changes to GitHub without explicit approval.
- Avoid destructive Git commands.

## Communication

- Communicate with the developer in Italian.
- Keep code, identifiers and technical documentation in English.
- Explain architectural decisions and trade-offs.
- Prefer practical examples over generic explanations.
- When working on workshop exercises, proceed step by step.
- Wait for confirmation before moving to the next exercise.
